Same tokens, one system

Every color, weight, and radius here is pulled straight from the brand file — Ink for dark surfaces, Royal Blue for primary actions, Cyan reserved for scan states only. Nothing was reinvented for this screen.

Scan stays the hero action

The scan reticle and viewfinder corners from the logomark reappear literally as the camera UI — the brand's signature isn't just a logo, it's the actual scanning interaction.

Mono still means "read data"

VIN strings, timestamps, and decoded fields stay in IBM Plex Mono everywhere — desktop table, activity feed, and mobile scan result — so scanned data is instantly recognizable from typed content.
